# 开发任务模板

读取根目录 DESIGN.md、design/system-v1/README.md 和本次数据合同，打开规范样本。实现任务指定的页面或组件，保持已确认的 Tensorlake 图形与排版规则。

开始前写明本页的主信息、主操作、数据来源、未知状态，以及将复用的 token/组件。先完成一个含真实长度内容的片段，再扩展到整页。

复用 --ah-* 变量；通用新组件放入资源包，业务布局留在页面。表格单位、来源事实、作者宣称、情景估计分别呈现。英文与中文、长文本、未发布/加载/失败/空状态均需处理。图片或视频只在承担具体视觉任务时制作。

用浏览器检查实际渲染，至少覆盖 1440、1024、390 和 320px；操作所有新增控件，检查键盘焦点和减弱动画。按 prompts/critic.md 进行独立截图审阅，最多先做两轮，并在 qa.md 或该页面的交付记录中记录修正。完成代码检查后交付页面和截图，明确剩余限制。
