# 一期本地数据链路实现计划

目标：在独立本地 PostgreSQL 中实际完成全量本体导入、模拟采集材料处理、指标计算、实验进度计算及历史回查。

设计依据：[一期数据库设计](../specs/2026-09-12-postgresql-business-schema-design.md)。技术：Python 3、psycopg 3、PostgreSQL 18、Docker Compose；Next.js 保持现有职责。

## 约束与决定

- 本地文件输入；本轮使用明确标记的合成材料。没有 Agent 上报、登录、Key、周报、发布或在线采集服务。
- 本体 v1.0.0 原件及既有 ID 保持不变；配置版本、数据批次和方法版本独立。
- 使用当前工作区新分支保留此前大量尚未提交的本体和设计工作；不从 HEAD 创建缺失这些文件的工作树。不提交混入其他工作。
- Docker 项目限定 `openaiwill-data-local`，只绑定 `127.0.0.1:7543`；凭据和运行产物位于忽略的 `data/`。不操作其他容器。
- NULL 与零分开；计数不直接转成完成百分比。实验方法只检验计算链路，不是正式能力基线。
- 完整批次在事务中导入和计算，全部验证后置 ready；重试同哈希复用，冲突拒绝，更正追加版本。
