# 进度计分方法 — auto-research 迭代系统设计

状态:已用户审阅通过;harness + v0 已实现(2026-09-16)。v0 = 先验-only 基线,首条 MLflow run:train_loss 0.714 / holdout_loss 0.25。日期:2026-09-16。

## 目的

把"AI 独立完成重大工作的进度"从**证据**算成一个**可辩护、带不确定区间、可复现**的估计,并把"计分方法本身"做成一台**能自动迭代、有客观损失、可外部观测**的机器 —— 用户看 MLflow 看板上的损失曲线,而不必跟每个设计决定。

**认识论前提(必须写死在心里):** 没有客观真值可"测到"。方法做的是**夹逼 + 收窄** —— 用最硬的证据定下界、用未知覆盖定宽度、用独立证据随时间收窄区间、用金标校准证明没跑偏。"损失下降"= 方法对一批**已知答案**的校准误差在下降;它是可证伪的收敛信号,**不是有泛化保证的 ML loss**(金标只有几十条,靠留出集 + 持续扩充防过拟合)。

## 系统组件

1. **真值集(truth set)** —— 人锚的"已知答案",损失的来源。`datasets/scoring/truth-set.v1.jsonl`,版本化提交。
2. **打分器(scorer)** —— 输入:事件层证据 + 一版**方法配置**;输出:每个工作节点的自主阶段(带区间)+ 加权滚动的总分。方法是**配置数据,不写死在代码**。
3. **评测器(evaluator)** —— 打分 vs 真值 → 一组客观指标(含主损失)。
4. **实验跟踪(MLflow)** —— 每次迭代 = 一条 run:`log_params`(方法配置)、tag/note(这轮改了什么、为什么)、`log_metrics`(损失等)、`log_artifacts`(每节点分数)。本地 Docker,见 `infra/`。
5. **迭代回路** —— 由 Claude 驱动(agent = 研究员):跑一版配置 → 读指标 → 改一处配置 → 再跑;降了留、没降退;损失见底则停。

迭代阶段**不碰**不可变的 `progress_values` 等段 3 批次表 —— 分数只落 MLflow + `data/experiments/`。方法定稿后再单独"提升"到 `progress_values`(本 spec 范围外)。

## 方法配置(迭代回路调的"超参")

一个版本化 JSON,含:

- **分类级联**:证据 → 大类 → 职业 → 任务 的逐级分类;每级候选数、置信阈值(低于阈值停在上层、标 unknown)。
- **证据分层**:T1 第三方 benchmark / 别家生产采用;T2 多方独立;T3 厂商自证;T4 纯营销宣称。
- **自主阶段尺**:0 无 · 1 辅助 · 2 有人监督 · 3 自主试点 · 4 自主生产。
- **阶段封顶规则**:T4≤1、T3≤2、T2≤3、T1≤4。AI 提议阶段,规则按证据等级封顶。
- **权重法**:就业人数份额(默认)/ 等额(缺数据回退)/ 薪资份额(备选)。
- **模型/提示词版本**:DeepSeek 分类与判级的 prompt 哈希、批量大小。

## 数据流

```
事件层(extracted_events + 证据) ─┐
                                  ├─ scorer(方法配置) → 每节点阶段+区间 → 加权滚动 → 总分(区间)
truth-set ─────────────────────── evaluator ← 每节点阶段
                                      │
                                      └→ MLflow(params + note + metrics + artifacts)
```

## 损失与指标

- **主损失 = 校准误差(非对称)**:对每条真值锚点,取方法预测的中央阶段 `p` 与期望 `e`;误差 = `max(0,|p−e|−tol)`,且**高估(p>e)罚 2×**(压制过度宣称)。损失 = 训练锚点上的均值。
- **留出损失**:holdout 锚点上的同一误差,**不参与调参**,用于发现过拟合(训练降、留出升 = 过拟合,回退)。
- 覆盖率(有评估的工作空间权重占比)、平均区间宽度、重跑方差(同配置跑两次的阶段分歧)、佐证占比(阶段由 T1/T2 支撑的节点比例)。

## 迭代回路与停止

- 起点 config v0(合理默认)。每轮改**一处**(封顶、置信阈值、prompt、权重法…)→ 跑 → MLflow 记录。
- **保留规则**:训练损失下降**且**留出损失未上升 → 保留;否则回退。
- **停止**:连续 N 轮训练损失无改善,或留出发散 → 停;报告当前"证据天花板"。
- **成本控制**:先只跑与真值锚点相关的证据子集(便宜);配置定稿后再放大到全量证据/全工作空间。
