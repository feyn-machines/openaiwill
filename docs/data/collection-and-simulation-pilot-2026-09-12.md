## 2. 真实采集量与边界

X 窗口：**2026-09-11 11:52:17 至 2026-09-12 11:52:17，UTC+8**。每账号最多一页、每页请求最多 20 条。先前的首请求出现 404；单次诊断返回 200 后开始第二轮。第二轮成功查询 **48 / 51** 个账号，在第 49 个 `BytePlusGlobal` 遇到 429 限流并停止，没有继续人物和采用方查询。

- 保留 **57 条 X 帖子**，来自 16 个账号；含 24 条回复。全部作者 ID 匹配，未发现身份不符记录。
- `BytePlusGlobal` 查询失败，`CozeHQ`、`Trae_ai` 未查询。32 个成功查询账号在本轮保留零条，不能据此断言没有发布。
- 57 条均返回点赞、转发、回复、引用、收藏、浏览数；记录读取时间，指标的服务端更新时间未知。
- Reddit 查询 `ClaudeAI`、`LocalLLaMA`、`AI_Agents`。接口各返回 30 条，采集器按时间排序后在全局上限内保留 **30 条**：18 / 2 / 10。不是每个社区全天全部帖子，也不是全平台声量。
- Reddit 保留样本的分数全部为 1，评论数合计 28，归档指标更新时间未知。保留原值，但本轮不据此判断“讨论热度很低”；没有抓取评论正文。

因此，**首轮待处理内容确实不多：87 条保留记录**。但请求数、接口限流和去重比存储量更早成为问题。下一轮应按账号分批、记录未完成游标，优先补覆盖；不要仅因返回内容少就提高并发。

原始采集文件位于本项目被 Git 忽略的 `data/collection/2026-09-12/`。可共享的[采集元数据](../../datasets/evidence/collection-pilot-2026-09-12.json)保留来源、覆盖、互动快照与正文哈希，不包含凭据或完整社交正文。

完整计算为保守 **9.73**、中心 **24.28**、乐观 **40.91**。展示时取一位小数，场景范围不是统计置信区间。**有材料的五组也不能由帖子统计推出相应完成度；这些数字仍全部属于 AI 判断。** 11 个无本轮直接材料的单元占 64 个权重点。

原专业组的 8 个权重点暂按 2 / 2 / 2 / 2 分给四条独立赛道，以保持原分母；这不是声称四行业规模相同。四者分别初始化先验，只在科学研究使用 E02。中心分由 24.38 变成 24.28 的 −0.10 全部记为分类与估计口径修订，不是 AI 倒退；具体见[修订记录](../../datasets/evidence/takeover-scope-revision-2026-09-12.json)。

这次生成的是带材料的初始基线，不是编造一段历史。`daily_progress_delta = null`；以后在同一范围、权重和估计规则下，才可比较新证据导致的状态变化。只修权重或改先验时，应记录方法修订。

输入与逐组理由见[当前独立赛道判断](../../datasets/takeover-pilot-2026-09-12.scope-v2.json)，输出含输入 SHA-256，见[计算结果](../../datasets/evidence/takeover-pilot-result-2026-09-12.scope-v2.json)。[原始输入](../../datasets/takeover-pilot-2026-09-12.json)与[原始输出](../../datasets/evidence/takeover-pilot-result-2026-09-12.json)保留用于比较。可从项目根目录重算：

这个脚本只校验并计算显式输入，不调用模型、不自行采集、不把帖子转换成数值。它保留未知权重：中心估计缺失时总分为空，不重新归一化。
