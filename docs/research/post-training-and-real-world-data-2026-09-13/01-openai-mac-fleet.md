## 一手资料能说明的技术机制

**OpenAI 的 CUA 官方说明（2025-01-23）**：模型结合视觉能力与强化学习，通过屏幕截图感知，再执行鼠标和键盘操作；官方也将上线后的用户反馈作为改进能力和安全措施的输入。这说明电脑交互与真实反馈都在其研究路线中，但文档没有披露这批采购或训练数据比例。[Computer-Using Agent](https://openai.com/index/computer-using-agent/)

**独立开源项目 Stoa（2026 年，采集时状态）**：其 README 展示一种分离式后训练方案，Mac 用 MLX 生成 rollout，CUDA GPU 更新权重。项目自称概念验证，尚未达到生产成熟度；示例包括数学任务，因此不能把所有 Mac rollout 都理解为桌面操作。它只用于解释技术分工，不能证明 OpenAI 使用相同实现。[Stoa 官方仓库](https://github.com/PluralisResearch/stoa)

这里的 rollout 指“一次尝试任务所产生的过程记录”，可以包含观察、模型输出、动作和结果。它不等于成功案例，更不等于已经整理好的训练样本。
