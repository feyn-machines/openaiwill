# 厂商如何使用反馈，以及真实工作如何成为评测材料

采集日期：2026-09-13（Asia/Taipei）。本文件区分官方政策说明、研究者报告和我们的推论；政策页面只能证明披露的处理规则，不能证明某一条对话实际进入了哪轮训练。

## 真实使用反馈的官方依据

| 来源及文档日期 | 已核查内容 | 能支持的论点与边界 |
| --- | --- | --- |
| [OpenAI：How your data is used to improve model performance](https://openai.com/policies/how-your-data-is-used-to-improve-model-performance/)，更新于 2026-03-13 | 个人服务内容可能用于训练，用户可退出；企业产品与 API 输入输出默认不用于训练，组织可主动选择共享 | 真实互动是其公开说明的改进来源。不能概括成所有服务、所有用户的材料都会用于后训练 |
| [Anthropic：Updates to Consumer Terms and Privacy Policy](https://www.anthropic.com/news/updates-to-our-consumer-terms)，发布于 2025-08-28 | 该次消费者条款更新让 Free、Pro、Max 用户选择是否允许相关数据用于模型改进，包含对应订阅下的 Claude Code；商业条款服务不属于这次更新范围 | 官方明确以开发者与模型协作调试为例，说明真实互动可以提供未来模型需要的反馈信号；这不是与合成数据进行受控比较的实验 |

政策的共同信号是：真实问题、纠正过程与用户判断具有开发价值。它们没有披露每种数据在模型中的占比、过滤流程或边际收益，也不能证明系统每次对话后立即更新权重。Anthropic 此处引用的是有日期的政策公告；不把公告中的全部保留期限等细节当作当前所有服务的通用规则。

## 已完成的真实商业任务可以成为评测材料

**SWE-Lancer（OpenAI，2025-02-18）**收集了 1,400 多个来自 Upwork 的软件工程任务，对应实际付款总额约 100 万美元，涵盖独立开发和技术管理决策。独立工程任务采用经有经验工程师三重核验的端到端测试；管理任务对照原聘用管理者的选择。它说明真实商业任务可以被整理成可评测材料；这些付款是原任务的实际报酬，不能理解成 AI 已赚取的收入。[官方介绍](https://openai.com/index/swe-lancer/)

对 openaiwill 的启发是：用户案例应尽量保留任务、交付物和验收依据，才能帮助判断 AI 到底能完成什么。SWE-Lancer 本身是评测证据，不证明将用户成功案例投入训练后一定优于合成数据。

**GDPval（OpenAI，2025-09-25）**完整集包含 44 个职业的 1,320 项任务，公开 gold 子集为 220 项。任务由资深从业者依据实际工作产物或相似构造的产物设计，包含参考文件与交付要求；平均经过五轮审查，再由职业专家盲评模型与人的产物。官方称自动评分器尚不能取代专家。其首版是单次交付评测，未覆盖完整工作中的多轮澄清和修改。[官方研究说明](https://openai.com/index/gdpval/)

这意味着“像真实工作”也有层次：从真实任务改编的题目、专业人士设计的代表性任务、现场发生的用户工作流，不能混为同一种证据。GDPval 的职业任务得分也不能直接换算为某个职业已被替代的比例。

## 哪些真实案例值得进一步采集

以下是本研究提出的采集模板，不是数据库迁移或用户投稿要求。材料由我们主动采集、整理；社区可以自愿补充。

| 要保留的信息 | 它回答什么问题 |
| --- | --- |
| 原始来源、发生时间、观察时间、贡献者角色 | 谁在什么时间作出了什么陈述？厂商还是实际使用者？ |
| 任务、行业、目标、起始条件和主要限制 | 真正需要完成的是什么？是否包含实际工作中的约束？ |
| 模型、产品、版本、工具和关键配置 | 哪套系统在什么条件下表现如此？ |
| 操作记录、交付物、人工修改与接管 | 结果是怎样产生的？哪些步骤仍由人完成？ |
| 成功标准、验收者与可复核依据 | “成功”是谁判断的？功能、质量或业务要求是否达成？ |
| 尝试次数、失败、重试、时间和成本 | 成功是否稳定？需要多少隐藏投入？没有记录时保留未知 |
| 持续使用或后续发现的问题 | 一次演示是否变成了可持续的工作方式？ |
| 分享范围、归因、公开与研究/训练用途许可 | 哪些材料可以保存、展示或进一步使用？这些许可分别确认 |

成功样本能展示已达成的能力；失败、人工纠正和被拒绝的结果能展示边界。只收集成功故事会失去分母：100 个成功案例不能说明成功率，除非同时知道尝试总数和抽样方法。

一份案例可以先有阅读与分析价值，随后在材料充分时成为评测候选；能否再用作训练材料，还取决于授权、格式、质量和目标模型。公共网页可读不等于拥有其原始文件的公开或训练许可。
